# AGENTS.md

Краткие правила для агентов в этом репозитории. Полные правила — [docs/03-guides/contributing.md](docs/03-guides/contributing.md).

## Сборка и проверки

```powershell
dotnet build BeautyOfNumbers.sln
dotnet test
```

Перед завершением задачи, меняющей код, прогонять `dotnet build` и `dotnet test`. Подробнее — [docs/03-guides/build-and-run.md](docs/03-guides/build-and-run.md).

## Git

- Ветки: `feat/…`, `fix/…`, `docs/…`, `chore/…` от `main`; нижний регистр, дефисы.
- Коммиты: английский, повелительное наклонение, без префиксов и точки в конце.

```text
Add Sacks layout
Fix preset round-trip for missing palette
```

- Тело коммита — только «почему»: пустая строка после заголовка, 1–3 строки.
- Один коммит — одно логическое изменение. Никаких `WIP`-коммитов.
- Коммиты и пуш делать только по явной просьбе пользователя.
- Вливание — squash-merge в `main`, история линейная.

## Что не коммитить

- Сгенерированные артефакты: `bin/`, `obj/`, `temp_preview.png`, `plot*.png`.
- Локальное состояние агента: `.kilo/` (уже в `.gitignore`).
- Секреты, токены, абсолютные локальные пути.

## Код

- Идентификаторы, имена файлов и коммиты — английский; документация — русский, README двуязычный.
- `Nullable` включён; предупреждения не игнорируются; file-scoped namespaces, один публичный тип на файл.
- Ядро без внешних зависимостей и без ссылок на WPF/Skia; математика только в `Core`, не в UI.
- Горячие циклы без LINQ и лишних аллокаций.
- Комментарии — только «почему», без объяснения очевидного; сложные формулы со ссылкой на [docs/04-math](docs/04-math/).

## Документация

- Изменение поведения, команд или архитектуры обновляет документацию в том же PR.
- Архитектурное решение — новый ADR в [docs/02-architecture/adr](docs/02-architecture/adr/) до реализации, старые ADR не переписываются.
- Отложенная идея идёт в [non-goals.md](docs/01-product/non-goals.md), а не в код «на будущее».
