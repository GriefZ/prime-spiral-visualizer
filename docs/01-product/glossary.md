# Глоссарий

Словарь доменных терминов. В коде используются английские идентификаторы из колонки «В коде».

| Термин | В коде | Значение |
| --- | --- | --- |
| Последовательность | Sequence | Правило, по которому числа попадают в кадр: диапазон `[start, start + count)` и фильтр (все / только простые). |
| Классификатор | Classifier | Функция, относящая число к классу. Базовый случай — простое / составное; класс задаёт цвет точки. |
| Раскладка | Layout | Правило отображения числа в точку: полярное `n → (r, θ)` или декартово `n → (x, y)`. |
| Спираль архимедова | ArchimedeanSpiral | `r = n`, `θ = n` (радиан) — текущая раскладка проекта: около 6,28 числа на оборот. |
| Спираль Сакса | SacksSpiral | `r = √n`, `θ = 2π√n`: точки равноудалены вдоль дуги, число витков растёт как `√n`. |
| Спираль Улама | UlamSpiral | Числа уложены прямоугольной спиралью по целочисленной сетке; простые образуют диагонали. |
| Гексагональная спираль | HexSpiral | Укладка чисел по спирали на гексагональной сетке. |
| Точка | Point / Point2D | Одна позиция в системе координат раскладки (данные, не пиксели). |
| Сцена | Scene | Список точек с координатами, размером и индексом цвета — результат раскладки, вход рендера. |
| Стиль | RenderStyle | Визуальные параметры: фон, цвета классов, функция размера точки, полотно. |
| Пресет | Preset | Именованный JSON, полностью описывающий сцену: последовательность + раскладка + стиль + вывод. |
| Схема пресета | Preset schema | Версионированный контракт JSON (`schemaVersion`); несовместимые версии отклоняются явно. |
| Живое превью | Live preview | Перерисовка изображения прямо в окне без промежуточных файлов на диске. |
| Студия | App / Studio | WPF-приложение целиком. |
| Решето Эратосфена | Sieve of Eratosthenes | Алгоритм поиска простых до N за `O(N log log N)`; целевая реализация — odd-only bitset. |
| Диапазон | NumberRange | `start` и `count` — какие целые числа рассматриваются. |
| Экспорт | Export | Сохранение сцены в файл (PNG, позже SVG/PDF) с заданными размером и DPI. |
| Батчинг | Batching | Группировка точек по цвету/размеру для быстрой отрисовки одним вызовом. |
| Рендер | Render | Процесс превращения сцены в пиксели или файл. |
| DPI | DPI | Точки на дюйм для метаданных экспорта; физический размер полотна не меняет. |
