# Вне рамок проекта

Список того, что сознательно не делаем в текущем горизонте. Каждый пункт можно пересмотреть только через обновление этого документа и roadmap.

| Не делаем | Почему |
| --- | --- |
| Web-версия, мобильные приложения | Десктоп на WPF — осознанный выбор; live-рендер миллионов точек в браузере не оправдан для пет-проекта. |
| 3D и GPU-шейдеры | Усложняют ядро и портируемость; текущая ценность — в 2D-паттернах. |
| Анимации и экспорт видео | Отдельный продуктовый сценарий; сначала стабильный статичный рендер. |
| Аккаунты, облако, галерея на сервере | Нет серверной части и не планируется; пресеты хранятся локально. |
| Другие последовательности (Фибоначчи, факториалы, mod-k и т.п.) | Выбран фокус — семейство спиралей. Классификаторы проектируются расширяемыми, но новые типы не входят в M0–M3. |
| Плагины и пользовательские скрипты | Опасность для безопасности и стабильности; не нужно до появления внешних пользователей. |
| Многопользовательская работа, синхронизация | Проект одиночный по природе. |
| Локализация интерфейса | UI на английском, документация на русском, README двуязычный. Локализация — только если появится запрос. |
| Поддержка Windows 7/8 и старых .NET | Целевая платформа — .NET 8 и актуальная Windows. |

## Отложенные идеи

Это не «нет», а «не сейчас». Идеи хранятся, чтобы не потерять, но не влияют на текущий план:

- экспорт SVG;
- пакетная генерация по папке пресетов (CLI);
- «галерея» примеров внутри приложения;
- сохранение пресета рядом с картинкой (sidecar JSON);
- дополнительные классификаторы чисел (близнецы, палиндромы);
- режим сравнения двух раскладок бок о бок.
