# Дорожная карта

Приоритеты зафиксированы: **инфраструктура и качество → производительность → live-рендер и интерактив**; визуальный фокус — семейство спиралей. Вехи не датируются: проект пет-овский, порядок важнее сроков.

## M0. Фундамент 🚧 (текущая веха)

Цель: превратить набор прототипов в репозиторий, который можно развивать.

Состав:

- реструктуризация решения: `Core`, `Rendering`, `Cli`, `App.Wpf`, `Tests` (см. [ADR-0001](../02-architecture/adr/0001-core-split-and-rename.md));
- перенос математики (простые числа, координаты) из UI и консоли в ядро;
- единая семантика диапазона чисел для CLI и UI;
- `.editorconfig`, включённый nullable, анализ в build;
- тестовые проекты и первые тесты: сито, раскладки, сериализация;
- CI на GitHub Actions: сборка + тесты на каждый push/PR;
- порядок в ветках: вмержить прототип (`vibe-coding`) в `main`, зафиксировать модель ветвления;
- лицензия (кандидат — MIT);
- README и `docs/` (этот набор);
- пример картинки перенесён в `docs/assets/`.

Критерий выхода: `dotnet build` и `dotnet test` зелёные в CI; поведение архимедовой спирали сохранено; ни одного продублированного алгоритма простых чисел.

## M1. Живой движок

Цель: убрать временные файлы и сделать интерактив.

Состав:

- рендер на SkiaSharp напрямую, единый пайплайн для превью и экспорта ([ADR-0002](../02-architecture/adr/0002-skiasharp-renderer.md), [ADR-0003](../02-architecture/adr/0003-live-preview-no-temp-files.md));
- решето Эратосфена (odd-only bitset) вместо пробного деления; диапазоны до 10^8;
- live-превью в WPF через `SKElement`, панорама и зум, debounce;
- отмена и честный прогресс по этапам;
- батчинг точек по цветовым группам и квантование размеров;
- бенчмарки: 100k / 1M / 10M точек.

Критерий выхода: метрики из [vision.md](vision.md) достигнуты; в рабочей папке не появляется `temp_preview.png`.

## M2. Студия

Цель: сделать инструмент, которым приятно пользоваться каждый день.

Состав:

- пресеты: сохранение, загрузка, список, `schemaVersion`;
- палитры и темы оформления спирали;
- экспорт PNG с заданным размером и DPI, за пределами экранного разрешения;
- семейство раскладок: архимедова, Сакс, Улам, гексагональная + параметры (поворот, направление, шаг);
- настройки приложения (стартовый пресет, папка экспорта).

Критерий выхода: UC-01, UC-02, UC-03, UC-05 работают по критериям приёмки.

## M3. Полировка и распространение

Состав:

- экспорт SVG (или PDF) — по результатам исследования библиотек;
- CLI: одиночный и пакетный рендер по пресетам;
- встроенная галерея примеров;
- публикация: `dotnet publish` (self-contained) и, при желании, установщик;
- горячие клавиши, полировка UX;
- документация дополнена по факту.

Критерий выхода: арт можно сгенерировать и забрать, не открывая IDE.
