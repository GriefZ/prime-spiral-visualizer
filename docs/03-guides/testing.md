# Тестирование

## Принципы

1. Тестируем то, что можно проверить без пикселей: математику, раскладки, валидацию, пресеты.
2. Графику проверяем смоук-тестами и детерминизмом, а не попиксельным сравнением с эталоном (эталоны хрупкие, Skia может менять рендер между версиями).
3. UI тестами не покрываем: вместо них — ручной чек-лист.
4. Производительность измеряем бенчмарками локально; в CI их не гоняем (шумные раннеры).

## Инфраструктура

- Фреймворк: xUnit (закрепляется в M0).
- Проекты: `BeautyOfNumbers.Core.Tests`, `BeautyOfNumbers.Rendering.Tests`.
- Запуск: `dotnet test`; фильтр — `dotnet test --filter Category=Layouts`.
- CI (M0): GitHub Actions, `windows-latest`, .NET 8: `dotnet build` + `dotnet test` на push и PR в `main`.

## Что покрываем (ядро)

### Решето

- Совпадение с эталонным пробным делением на отрезках 10^5–10^6.
- Границы: `limit < 2`, `limit = 2`, `limit = 3`, простые-близнецы.
- Первые 10 000 простых совпадают с таблицей.
- `IsPrime` не аллоцирует и не выходит за границы для любого значения 0..limit.

### Раскладки

- Точечные значения: `Map(1)`, `Map(2)`, `Map(10)` для каждой раскладки.
- Инварианты: архимедова — радиус растёт линейно; Сакс — расстояние вдоль дуги постоянно; Улам — соседние числа на соседних клетках сетки; гекс — корректные соседи в axial-координатах.
- Параметры: поворот на `2π` даёт ту же точку; смена направления зеркалит точку.
- Раскладка не падает на `number = 1` и больших значениях.

### Валидация

Таблица невалидных запросов: отрицательный `Count`, `Start < 1`, переполнение `End`, пустая палитра, нулевые размеры вывода, `limit` меньше конца диапазона.

### Пресеты

- Круговой прогон: `Preset → JSON → Preset` эквивалентен исходному.
- Стабильный порядок свойств.
- Неизвестная `schemaVersion` → явная ошибка.
- Отсутствующие необязательные поля подставляют значения по умолчанию.

## Что покрываем (рендер)

- Смоук: 10k точек, канвас 512×512, без исключений.
- Детерминизм: два прогона одного запроса → одинаковый хэш пикселей.
- Границы сцены: пустая сцена и сцена из одной точки не падают.
- Отмена: `CancellationToken`, отменённый заранее, прерывает `Build` быстро.
- Экспорт: файл создаётся, ширина/высота соответствуют `OutputOptions`.

## Ручной чек-лист UI (перед релизом вехи)

- [ ] Запуск: окно открывается, превью появляется без действий пользователя.
- [ ] Смена раскладки меняет картинку, не меняя диапазон и цвета.
- [ ] Быстрое перетаскивание слайдера не подвешивает окно и не копит очередь.
- [ ] Отмена тяжёлой генерации возвращает предыдущее превью.
- [ ] Панорама/зум работают; двойной щелчок сбрасывает вид.
- [ ] Экспорт PNG: размеры и DPI соответствуют настройкам.
- [ ] Пресет сохраняется, перезапуск приложения, загрузка — картинка та же.
- [ ] Битый JSON пресета: понятная ошибка, приложение живо.
- [ ] В рабочей папке не появляются временные файлы.
