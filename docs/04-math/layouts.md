# Раскладки (спирали)

Раскладка — правило, по которому число `n` превращается в точку на плоскости. Раскладка не меняет математику чисел, но определяет, какие закономерности видны глазом. Поэтому раскладка — сменный компонент ядра (`ISpiralLayout`, см. [core.md](../02-architecture/core.md)).

## Общая модель

Для полярных раскладок:

```text
r = r(n)
θ = θ(n)          (радианы)
x = r · cos θ
y = r · sin θ
```

В сцену попадают декартовы координаты: рендер не знает, полярная была раскладка или прямоугольная. Общие параметры всех раскладок: `Scale` (масштаб), `Rotation` (поворот), `Clockwise` (направление намотки).

## Архимедова спираль (текущая)

```text
r = n
θ = n
```

- Точка `n` лежит на радиусе `n` и угле `n` радиан.
- Один оборот — `2π ≈ 6,28` числа, поэтому спираль имеет широкий шаг и хорошо читается на десятках тысяч чисел.
- Это раскладка прототипа: в старом коде `x = y = n`, а полярную интерпретацию делал OxyPlot.
- Обобщение: `r = a·n`, `θ = 2π·n / k`, где `k` — «чисел на оборот».

Свойства: расстояние между соседними числами вдоль радиуса постоянно и равно `a`; угол между соседними числами тоже постоянен. Паттерны возникают из `n mod k`.

## Спираль Сакса

```text
r = √n
θ = 2π·√n
```

- Точки равноудалены **вдоль дуги**: длина дуги пропорциональна `n`, поэтому шаг между соседними числами одинаков.
- Число витков растёт как `√n`, поэтому по мере удаления от центра структура уплотняется, а не растягивается.
- На ней классически наглядны «лучи» простых, связанные с квадратичными формами.

Свойства: `θ/2π = √n` — угол измеряется в «корнях»; радиус линейно связан с углом: `r = θ / 2π`, то есть точки лежат на архимедовой спирали, но равномерно по длине.

## Спираль Улама

Прямоугольная укладка: `1` в центре, далее по целочисленной сетке — вправо 1, вверх 1, влево 2, вниз 2, вправо 3, вверх 3, … Обход по часовой стрелке или против.

- Это не полярная раскладка: `n → (x, y)` на решётке.
- Диагонали спирали — квадратичные полиномы от номера витка (например, нечётные квадраты на одной из диагоналей), поэтому простые выстраиваются вдоль диагоналей, а «провалы» — вдоль линий, где значения заведомо составные.
- Классический пример: многочлен Эйлера `n² + n + 41` подряд даёт простые для `n = 0..39` — на спирали это видно как длинная диагональ.

Реализация: итеративный обход с длинами шагов `1,1,2,2,3,3,…`; координаты — целые числа, масштаб применяется рендером.

## Гексагональная спираль

Укладка чисел по спирали на гексагональной сетке (axial-координаты). Кольцо номер `k` содержит `6k` клеток; полный шестиугольник радиуса `k` — `3k(k+1) + 1` клеток.

Реализация: обход шести направлений гексагональной сетки с длинами шагов, растущими на каждом кольце. Даёт менее привычную, но более «плотную» картину: упаковка точек выше, чем у квадратной решётки.

## Сравнение

| Раскладка | Тип | Формула / правило | Что видно |
| --- | --- | --- | --- |
| Архимедова | полярная | `r = n`, `θ = n` | Широкие рукава; паттерны по `n mod 2π` и делителям |
| Сакс | полярная | `r = √n`, `θ = 2π√n` | Равномерная дуга, «лучи» простых, уплотнение к краю |
| Улам | решётка | обход квадратами `1,1,2,2,3,3,…` | Диагонали простых, квадратичные полиномы |
| Гексагональная | решётка | кольца по 6 направлений | Плотная упаковка, шестилучевая симметрия |

## Параметры и их влияние

| Параметр | Влияние |
| --- | --- |
| `Rotation` | Поворот всей картины; при `2π` результат совпадает с исходным. |
| `Clockwise` | Зеркалит направление намотки. |
| `Scale` | Общий масштаб координат; на вид в автоподгонке не влияет, важен для ручного вида. |
| `Start` | Какое число считается первым в кадре (диапазон). |
| Шаг/обороты (архимедова) | Сколько чисел на оборот: больше — плотнее витки. |

## Требования к реализации

1. Чистая функция без состояния: одинаковый вход → одинаковая точка.
2. Никаких аллокаций в горячем цикле.
3. Числовые проверки для каждой раскладки — в тестах (точечные значения `Map(1)`, `Map(2)`, `Map(10)` и инварианты из [testing.md](../03-guides/testing.md)).
4. Формулы в коде комментируются ссылкой на этот документ, а не пересказом.
